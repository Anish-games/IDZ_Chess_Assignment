♟️ Chess Game
A 2D Chess game built in Unity using C#.

About
This is a chess game where you can select and move chess pieces on an 8x8 board. All standard pieces (King, Queen, Rook, Bishop, Knight, Pawn) are included with their proper movement rules.

How It Works
Select a Piece – Click on any chess piece to select it
View Legal Moves – The board highlights all valid moves for that piece
Capture Enemies – Enemy pieces that can be captured are shown with a different highlight
Move – Click on any highlighted tile to move the selected piece there
